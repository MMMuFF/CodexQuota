# CodexQuota v0.8.2

## 修复悬停数字闪烁

- 额度文字直接按可用宽度生成最终显示内容，不再先写入长文案、下一帧再切回紧凑文案。
- 相同额度不再强制重复排版；真实额度变化和侧栏缩放仍正常更新。
- 保留额度与详情卡的鼠标感应区域，让系统自动跟随可见范围，避免重复注册触发悬停反馈循环。
- 悬停下划线、侧栏跟随和原有用券安全策略保持不变。

## 同时包含此前已合并的新功能

从上一公开版本 v0.7.3 升级，还将获得：

- 分区详情卡：大号剩余额度、右侧重置日期、灰色时间条与蓝色消耗条、账户权益、公共公告和底部工具栏。
- Tibo 公共重置/发券预告及第三方预测，独立于个人账户周期；没有明确预告时不猜日期。
- 日期自动采用电脑当前时区，处理跨日和夏令时；悬停“本机时间”查看时区与来源说明。
- 退出入口移至右下角“··· → 退出…”，仍需确认。

## 安装与升级

1. 下载本 Release 的 `CodexQuota.zip`（Apple Silicon / macOS 13+）。
2. 先退出正在运行的 CodexQuota，将解压后的 App 放入 `/Applications`，替换旧版。
3. 打开应用，悬停昵称旁额度查看详情；如果辅助功能授权失效，请在系统设置中重新授权该固定路径。

安装包为 ad-hoc 签名，未经 Apple 公证。请仅从本仓库下载；Intel Mac 可自行从源码构建。程序不会修改 Codex 安装包。

## 验证与边界

76 项本地检查（60 核心 + 16 AppKit）已通过，含连续重复更新、缩放适配、悬停下划线、感应区域稳定性与模拟服务安全回归。Release 构建、签名及 ZIP 完整性验证通过。

组件检查使用演示数据和测试进程自有窗口；不读取真实 Codex 辅助功能界面，不消耗真实重置券。系统辅助功能授权及真实跨应用悬停交互仍以本机实际效果为准。

公共公告通过独立只读请求访问 codex-resets.com，不发送账号凭据；网络服务会收到正常连接信息（如 IP）。公告失效不影响个人额度读取。
