# CodexQuota v0.8.4

## 中文

### 新增

- App 跟随系统或单独为 App 设置的首选语言：中文使用简体中文，其余语言使用英文。修改语言后请重新打开 App。
- 额度、进度、预计耗尽时间、会员与重置券、公共重置信号说明、确认弹窗和错误提示均提供中英文文案。
- GitHub 提供互相链接的中文与英文 README，并加入英文界面示例图。
- 语言与时区独立：日期仍按电脑当前时区显示，第三方公告原文不自动翻译，不增加翻译服务请求。

### 修复

- 修复 #8：短昵称与带文字的语音按钮同时出现时，额度过早退化为仅百分比。
- 根据昵称和头像的可见边界利用空白，同时保留语音、帮助按钮的安全间距；无法可靠读取边界时采用保守布局。
- 空间不足时按“完整信息 → 紧凑信息 → 百分比与日期 → 仅百分比”逐级缩短，英文日期同样适配。

### 安装与验证

- 下载 `CodexQuota.zip`，退出旧版后将 App 放入“应用程序”。安装及辅助功能授权步骤见 README。
- 提供 `CodexQuota.zip.sha256` 校验文件。发布包适用于 Apple Silicon，使用 ad-hoc 签名，未进行 Developer ID 公证；更新后可能需要重新授权辅助功能。
- 本地通过 63 项核心测试、20 项 AppKit 测试及中英文专项检查，并验证 Release 构建和 ZIP 解压后的签名。
- 本次验证包括模拟昵称边界、280–360 点侧栏和实际 AppKit 字体排版；未在问题提交者的真实 Codex 窗口中验收。若仍有布局问题，请附 Codex 版本及截图反馈。
- 本版不改变账户隔离或重置券兑换逻辑，测试不消耗真实重置券。

## English

### Added

- The app follows the preferred system or per-app language: Simplified Chinese for Chinese, English otherwise. Reopen the app after changing its language.
- Bilingual quota, progress, exhaustion estimates, membership and credit details, public reset signals, confirmation dialogs, and errors.
- Linked Chinese and English READMEs, including an English UI preview.
- Language remains independent of time zone. Dates use the computer’s current time zone; original third-party announcement text is preserved without translation-service requests.

### Fixed

- Addresses #8: quota information collapsed to a percentage too early with a short nickname and a labeled voice button.
- Reclaims space using visible nickname/avatar bounds while preserving voice/help spacing; falls back conservatively when bounds are unreliable.
- Adds a percentage-and-date tier before percentage-only text. English dates use the same progressive fitting behavior.

### Installation and verification

- Download `CodexQuota.zip`, quit the previous app, and place the app in Applications. See the README for installation and Accessibility permissions.
- Includes `CodexQuota.zip.sha256`. The binary is for Apple Silicon, ad-hoc signed, and not Developer ID notarized. Accessibility permission may need to be granted again after updating.
- Local verification passed 63 core checks, 20 AppKit checks, bilingual checks, the Release build, and signature verification of the ZIP-extracted app.
- Coverage includes synthetic account geometry, 280–360-point sidebars, and real AppKit font fitting. The reporter’s live Codex window has not been verified; please report remaining layout issues with the Codex version and a screenshot.
- Account isolation and credit redemption behavior are unchanged. No real reset credits were consumed during testing.
