# CodexQuota v0.8.3

## 更新内容

- **更直观的消耗对比**：额度已用进度在上，时间已过进度在下，紧邻均速预计用完文案。
- **预计耗尽竖线**：在时间条上标出按本周期平均消耗速度预计用完的位置。例如时间已过 20%、额度已用 50%，标记位于周期的 40% 处。预计重置前用不完、尚无法估算或数据不可用时隐藏；恰好在重置点用完时显示在最右端。
- **公共重置信号说明**：有预测时显示接口提供的非官方概率和信号强度；缺少概率时明确写“概率未提供”，不自行补值。信号级别为“信号较强 / 信号增强 / 强度未知”，并标注“非执行保证”。
- **区分预告与执行**：明确预告显示“已预告 · 待执行”；预告时间已过但尚未确认时显示“待确认”。历史公告与第三方观测分别说明，不代表当前账户已到账。
- README 同步说明竖线含义、预测限制与状态区分。沿用 v0.8.2 的悬停防闪烁修复。

## 预测的边界

个人额度耗尽时间是均速估算，周期初期可能波动较大，不是确定的耗尽时刻。

公共重置概率来自 Codex Resets 的第三方 AI 分类，不是 Tibo 或 OpenAI 的承诺。接口未提供历史命中率，80% 不代表已验证的八成准确率。预测有效期也不是预计重置时间。

本次更新不改变账户凭据读取、手动用券确认或临期自动用券条件，不会为了测试使用真实重置券。

## 安装与更新

下载本页的 `CodexQuota.zip`，退出旧版后解压，将 `CodexQuota.app` 替换到 `/Applications`（应用程序）并打开。源码用户可运行 `./scripts/install.sh`。

压缩包为 macOS 原生 Apple Silicon 构建，采用 ad-hoc 签名，未做 Developer ID 公证。重建后 macOS 可能要求重新授权“辅助功能”；如额度未出现，请检查系统设置中的该项权限。不要安装多个同名副本。

`CodexQuota.zip.sha256` 用于校验下载文件：在两份文件所在目录运行 `shasum -a 256 -c CodexQuota.zip.sha256`。
